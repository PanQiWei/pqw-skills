# 一程交付声明

一程交付完毕时填，贴进最后一份汇报件。切片级只在收口记录里写一句「清了什么」，用不着这份。

- [ ] 全部切片状态与提交历史一致，最终 head <短 sha>
- [ ] spec 验收标准逐条有证据：<指向最后一份汇报件>
- [ ] 不变式对照逐条有验证
- [ ] 一程全量读数：<指向收口清单末尾「一程全量读数」那份记录；项目合入检查已覆盖时写那条命令与结果出处>
- [ ] 清了什么：<一句，例如「子代理工作树与分支、系统临时目录本程子目录、项目 tmp 的过程材料已删，宿主定时任务已删」；人没看过而留下的过程材料写路径>
- [ ] 待人决定的事项：<列出，或「无」>

## 待人验收

必填。它和「待人决定的事项」分开：那边要人判断，这边要人动手。每行一样交付的行为；没有要验的写「无」。收回时，设计会话先看这里勾完没有。
