# 清理清单与交付声明

切片级只填「切片清理」；一程级填全，并把交付声明贴进最后一份汇报件。

---

## 切片清理：切片 <号>

脚本输出（`--scope slice`，先列后删）：

| 类型 | 条目 | 处置 |
| --- | --- | --- |
| <工作树 / 分支> | <> | <已删 / 跳过：原因> |

- [ ] 跳过的条目每条有原因，没有「待会再删」
- [ ] 本切片的探路件已删或已转成正式内容
- [ ] 留下的只有下一切片要用的东西

## 一程清理

脚本输出（`--scope run`）：

| 类型 | 条目 | 处置 |
| --- | --- | --- |
| <工作树 / 分支 / 临时目录 / 过程材料> | <> | <> |

- [ ] 系统临时目录本程子目录已删
- [ ] 宿主里的定时任务已删，后台循环已停
- [ ] 过程材料：<已删 / 人未看过，保留在 <路径>>
- [ ] 项目专有的清理项（从接入点取）：<已做 / 未提供>

## 一程交付声明

- [ ] 全部切片状态与提交历史一致，最终 head <短 sha>
- [ ] spec 验收标准逐条有证据：<指向最后一份汇报件>
- [ ] 不变式对照逐条有验证
- [ ] 清理已做（上两节）
- [ ] 待人决定的事项：<列出，或「无」>
