# 清理

清理是交付的一部分，不是可选项。一程交付完毕的声明要包含「清理已做」。

## 两个尺度

| 时机 | 清什么 | 留什么 |
| --- | --- | --- |
| 每个切片交付时 | 不必留给下一切片的中间产物与数据文件：子代理的工作树、工作分支、临时数据、本切片的探路件 | 下一切片要用的上下文包增量、已合回的代码、正式文档、汇报件 |
| 一程完整交付后 | 全盘：本程全部子代理工作树与分支、系统临时目录下 `pqw-skills/<会话标识>/<一程标识>/` 整个子目录（含汇报件）、项目 tmp 里本程的过程材料、宿主里的定时任务 | 已进唯一源的正式文档、已合入的代码、变更记录 |

## 规则

- 先列后删。先出清单，核对没有未合回的提交和未落盘的事实，再动手。
- 删子代理的工作树和分支时，先确认它们已经合回或已经放弃，并且没有别的会话在用。工作树干净或分支已合并，都不能证明可以强制删除；仍有执行者持有的树不删。
- 汇报件用完即弃，不迁进仓库留档。要长期留的事实写进正式文档。
- 过程材料（spec、plan、整程包）在人看过之后再清；人没看过就留着，在交付声明里写明。
- 删除不可逆。脚本只在显式要求时动手，每条独立执行，中断不留半删状态。

## 脚本

[`scripts/cleanup.mjs`](scripts/cleanup.mjs) 做 Git 工作树、分支和临时目录三类，按名字前缀匹配本程的子代理产物。默认只列不删，`--apply` 才删。它自动跳过主工作树、当前分支、有未提交改动的工作树、没合进当前 HEAD 的分支，并写明原因。

```sh
node <技能目录>/scripts/cleanup.mjs --scope slice --prefix <前缀>            # 切片级，只列
node <技能目录>/scripts/cleanup.mjs --scope slice --prefix <前缀> --apply    # 切片级，删
node <技能目录>/scripts/cleanup.mjs --scope run --prefix <前缀> --project-tmp <目录> --apply   # 一程级
```

项目专有的清理项从项目接入点取，脚本不管。宿主里的定时任务由主代理按 `one-lesson-rule` 自己删。

## 产出

填[清理清单与交付声明](checklist-template.md)。切片级只填前半；一程级填全。
