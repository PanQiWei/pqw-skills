# spec 模板

方法按 Matt 的 `to-spec`：综合已有输入，不重新访谈；先找测试接缝，越高越好、越少越好。本模板在它的骨架上加入定义期的产出、不变式对照、跨域概念的五问和失败语义。

使用规则：

- 放在项目 tmp 下本程的目录，例如 `tmp/<一程名>/spec.md`。正式形状与长期契约归项目的正式文档，本文件不成为第二源。
- 只写差额。整程上下文包已写的只引用，不重抄。
- 每条依据带链接或精确修订，不写只在对话里出现过的说法。
- 不写具体文件路径与代码片段，除非原型给出的形状比文字更精确（状态机、类型形状、schema），这时只保留决定所需的部分并注明来自原型。「责任分级」一节写的是成员或目录，不在此列。
- 项目有自己的 spec 模板时以项目的为准。
