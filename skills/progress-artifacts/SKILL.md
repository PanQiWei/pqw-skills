# 进展汇报件

## 形式

- 架构图、UML：实现在架构层面长什么样，和之前比有什么区别，还缺什么。
- 快速 demo：重要的产品功能做成可增量更新的 demo，让人直接上手。
- 可视化文档或交互式网页，一眼能看出变了什么。

## 性质

用完即弃。目的不是留档，而是让人的注意力停在架构、产品、交互体验三个层面，同时把控进度、健康度并快速反馈。

## 放在哪

统一放操作系统自己的临时目录，各操作系统一致，借用系统的定期清理：

```
<系统临时目录>/pqw-skills/<会话标识>/<一程标识>/artifacts/
```

系统临时目录按 Node 的 `os.tmpdir()` 或各语言等价接口取值：Linux 与 macOS 通常是 `$TMPDIR` 或 `/tmp`，Windows 是 `%TEMP%`。汇报件不进仓库，不进项目 tmp。

## 清理

切片交付和一程交付后的清理归 `cleanup`，调用 Skill 工具加载它。
