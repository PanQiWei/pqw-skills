# 交接信息包模板

交接期「交出」那一步的产出，写在交接点核对单过了之后；「切片大纲」一节在定程时先写好。它让一个没有定义期上下文的会话只读这一份包和它链接的 spec 与正式文档，就能从第 7 步开工。放在哪：跨会话用工单时，它就是这一程那张工单的正文；一个会话走完或退回到文件时，放在接入槽位「交接信息包与路线图放哪」指的地方，没填放项目 tmp 下本程目录的 `handoff.md`。

写法：只放指针和当场可核的几项，不复述正式文档。每个依据钉在一个提交上，交付会话读到的就是设计会话认可的那一版。十个二级标题照抄，顺序不变，`check-plan --handoff` 按它核结构。

包里只有这一程：不写后面还有几程，不写下一程做什么。路线图归设计会话，不进包。

这份包是设计会话交给交付会话的一次转手：对话里的取舍与理由，没写进包和正式文档的都会丢。转手会丢信息，回路越紧越稳，一块多大由接的一方验得完多少定。做法加载技能 `think-closed-loop`。
