# 领域影响分析与顶层设计

## 回答的问题

- 哪些现有领域受影响，要不要新领域。
- 谁是这一程的重点领域，谁是次要，谁只是连带。
- 系统全局上这些领域怎么摆。

## 产出

- 领域影响分级。
- 最粗粒度的架构决定，作为后续细化、论证、实施、验收的总边界。
