# 用确定性证据说话：验收与交回

## 完成只认验收标准

- 切片与一程的完成只认 spec 的验收标准。每条标准一个结论：达到，或未达到并写缺哪份证据。
- spec 没写的标准不补。标准写不出一条能核对的命令或文件，说明 spec 还没写清，回到 spec。
- 验收与评审都用确定性上下文：测试、证明、读数、变异、对照 spec 逐条核。不做对抗性评审，它的上下文和实施方不对齐。

## 子代理的交回

- 原始结果写进交回文件：改了哪些文件、每条验收的命令、退出码与输出尾部、变异表。报告只带结论、提交号、证据文件的路径与偏离。报告是指针，不是证据：只读报告，失败会被写成成功。
- 主代理用工作树事实核：分支头、提交、日志。在写者的分支头上自己复跑关键检查，再下结论。
- 验收失败先在基线上复跑同一检查，分清新失败与旧失败。
- 怎样写简报、怎样防作弊归 `delegate-brief`。

## 向人汇报

- 给人看的结论也分量过的、推出的、猜的。没验证的写没验证。
- 待人决定的事附自己的建议、依据与风险，不编造决定来填篇幅。
