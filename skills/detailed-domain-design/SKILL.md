# 细化领域设计

## 三件事有机结合

- DDD 领域建模。
- 遵循 SOLID 的面向对象关系模型。
- 仓储设计：I/O 性能、写入与查询性能在设计期定下来，不留给实施期顺手写。

## 为什么仓储要单独花功夫

没有专门设计时，当前的代理在写存储和 I/O 时很容易写出性能差的代码。
