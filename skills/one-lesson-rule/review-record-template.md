# 回看记录

哨兵子代理每轮写一份到汇报目录 `sentinel/<UTC 时间>.md`，消息原文附在末尾。主代理的处置写进 plan 的进度总览，格式固定为一行 `处置 <n>（<UTC 时间>）：<动作>；<理由>`，脚本据此算「连续两轮无处置」的信号。

## 结论（四选一）

- <继续 / 建议主代理介入：<哪一处、为什么> / 建议停下问人：<命中 spec 待决事项哪一条> / 子代理健康问题：<哪个、信号>>
