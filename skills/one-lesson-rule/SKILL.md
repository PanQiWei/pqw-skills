# 一堂课法则

## 节拍

- 主代理：每 45 到 60 分钟一次顶层回看。
- 子代理：运行到 30 分钟及其整倍数时一次健康检查。

## 回看什么

- 总体进度有没有偏离 spec 与 plan。
- 是不是在某个局部兜圈子。
- 上下文有没有因为反复压缩或累积而腐化。

## 常规出口

升更强的模型，提推理档位，主代理直接介入指导，主代理接手。

## 为什么

这是对模型自身缺陷的工程补偿：不假设代理能自己察觉腐化，用时间盒强制回看。
