# 应然与实然：优化与重构

## 性能优化

- 应然问：这件事的耗费只应该取决于什么，哪些功是回答问题必须做的。例：差分变异回答「这次的改动有没有被测试守住」，所以只该变异改动的行，不该变异改动行所在的整个函数。
- 实然是测量：耗费实际花在哪。没有测量就没有实然，不优化。
- 差异是不必须的功。先去掉它，再考虑让必须的功跑得更快。
- spec 写了性能要求，或测量显示不满足时，优化属于做对，不属于做好一轮。两轮的分法见 `think-right-then-well`。
- 读数的命令与范围归 `slice-closeout`。

## 重构

- 应然问：这个模块按它真正的职责，今天从头设计是什么形状。
- 实然是现在的形状。对每一处多出来的东西问：当初为什么加，那个理由现在还成不成立。
- 差异是向目标形状收拢的步骤。理由已不成立的，删；理由还成立的，留并写明理由。
- 先删后加：先去掉不该在的东西，再在更简单的底子上建。
- 重构不改行为。行为要变，先改应然，那是另一件事。
