# pqw 模式

回答的问题：这件事属于哪个场景，按什么次序过哪几个想法，去哪个技能。本技能只路由，做法在被指到的技能里；执行风格加载技能 `pstack:poteto-mode`。

三条轴。场景轴：这件事是哪一类工作。思维轴：七个想法，每个场景都用，篇幅不同。流程轴：13 个环节，只属于「大改动」一个场景。

七个想法：拆 `think-orthogonal`，找差异 `think-ought-vs-is`，定形 `think-model-first`，建 `think-right-then-well`，证 `think-evidence`，转手 `think-closed-loop`，问 `think-unknowns`。每个一句在[常驻卡片](../single-session-dev-flow/resident-card.md)，三句动作在同名技能。下面两张表只写叫法。

## 先看叠加的条件

条件与场景正交。命中几条就叠几条，叠在选中的场景上。

| 条件 | 叠加什么 |
| --- | --- |
| 没有人可以问，也没有人验收 | 把[无人卡片](../single-session-dev-flow/unattended-card.md)接在常驻卡片后面 |
| 碰到状态与操作：有生灭的对象、状态机、「不该发生」的分支 | 定形，先于写代码 |
| 一句话有两种读法，或有不知道的事 | 问 |
| 准备派子代理，或把一件事交给人 | 转手；派法加载技能 `delegate-brief`，只用两个判据、派发门与交回 |
| 看到人这一侧的风险：需求不清、不值得做 | 说一次，加载技能 `candid-friend` |

## 再认场景

从上往下判，第一条命中的为准。去向分三档。必须：认出场景就加载，不跳过。默认：加载；这件事小到不值得时可以跳过，在回复里说一句为什么。候选：默认不加载，命中写明的条件才加载。

| 场景 | 判定 | 过哪几个想法 | 去向 |
| --- | --- | --- | --- |
| 大改动 | 要动领域边界、要同步跨域的消费者，或大到要人离开再回来验 | 全部 | 必须：加载技能 `single-session-dev-flow`，完整走 |
| 评审 | 产出是对一份已有改动的判断，改动是别人或子代理写的 | 证，找差异 | 默认：加载技能 `mattpocock-skills:code-review`；只核承诺的有没有做到，不做对抗性评审，证据按 `think-evidence` 的「验收与交回」 |
| 回答一个问题 | 产出是结论，写的代码不留在仓库 | 问，证 | 候选：答案在仓库里就直接读，不加载。要读仓库外的资料才加载技能 `mattpocock-skills:research`；要跑出来才知道才加载技能 `mattpocock-skills:prototype`；选型看 `tech-research-and-reuse` 的复用次序 |
| 定位问题 | 有现象，手里没有一条会变红的复现 | 找差异，证；同类问题第二次出现时拆 | 必须：加载技能 `mattpocock-skills:diagnosing-bugs`；根因有了证据，转「改一个行为」 |
| 重构与优化 | 外部可见的行为不变，改的是结构或性能 | 找差异，建（不加能力，只改实现），证 | 默认，按改的是什么二选一。结构：加载技能 `mattpocock-skills:codebase-design`，前后读数用 `slice-closeout` 的结构读数与差分变异脚本（TypeScript 与 vitest 的项目）。性能：加载技能 `pstack:benchmark-checklist` |
| 改一个行为 | 其余写代码的工作：修一个缺陷，或一个领域之内的新能力 | 找差异，拆（要求逐条列），建，证 | 默认：加载技能 `mattpocock-skills:tdd`；测试绿了之后单独一轮，按 `think-right-then-well` 的品味核对单。一两行的修复可以跳过 |

都不合适时不硬套最近的一行：用拆自拟一个次序，在回复里说出来；工作大而没有先例，加载技能 `pstack:figure-it-out`。

## 四条规矩

- **先加载去向，再动手。** 认出场景之后，「必须」与「默认」两档的技能先加载再动手，照它做；读到这张表不等于读过那个技能。点名的技能没装时，按想法一列自己做，在回复里说明没装的是哪个。想法一列里拿不准的，加载同名的 `think-` 技能。
- **只升级，不缩水。** 做着发现命中「大改动」的判定，就停下，说一句「这件事够格走完整的流」，转过去。场景只组合想法与能单独用的工具，不组合阶段：定约、定程、交出与收回归 `pass-the-baton`，只在完整的流里出现。
- **说出选了哪一行。** 第一条回复里一句话：场景、命中判定的理由、叠加了什么、去向是加载了还是跳过。跳过「默认」档要写为什么，不写理由就加载。人说不对就换。
- **单点修改不过路由。** 指到文件与行、一句话说得清的修改直接做，常驻卡片的七个想法照用。
