# 交接信息包模板

定义期的最后一个产出，写在交接点核对单过了之后。它让一个没有定义期上下文的会话只读这一份包和它链接的正式文档，就能从第 7 步开工。放在哪由接入槽位「交接信息包放哪」定，没填时放项目 tmp 下本程目录的 `handoff.md`。

写法：只放指针和当场可核的几项，不复述正式文档。每个依据钉在一个提交上，交付会话读到的就是设计会话认可的那一版。九个二级标题照抄，顺序不变，`check-plan --handoff` 按它核结构。
