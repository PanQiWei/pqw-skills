# 前置消熵

## 两个尺度

- 整程开工前：便宜的子代理整理整程依赖的上下文信息包；主代理完成关键模块的细化架构设计与必要的技术验证。
- 每个切片开工前：补这个切片额外需要的上下文，做它的技术细节设计与验证。

## 为什么

把不确定性从「实施时才发现」搬到「动手前就消除」。信息包一次整理，之后只增补。
