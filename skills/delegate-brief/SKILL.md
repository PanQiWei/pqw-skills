# 派发简报

## 四样东西缺一不可

1. 清晰的目标与指令。
2. 行动边界：写范围、禁令、停点、完成即止。
3. 必须遵守的规格。
4. 参考用的信息包。

## 为什么

缺任何一样，子代理的行动就不可控、难预测。

## 外部技能

派发的流程调用 Skill 工具加载 `pstack:poteto-mode` 中的子代理章节。
